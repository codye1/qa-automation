## Мета роботи

Розгорнути робоче середовище для автоматизації тестування на базі Node.js і TypeScript, налаштувати засоби контролю якості коду, розробити та запустити перший автоматизований тест, оформити результат як версіонований проєкт.

## Технології

- Node.js 20+ та npm
- TypeScript 5 (режим `strict`)
- Vitest + `@vitest/coverage-v8` (тести та покриття)
- ESLint + typescript-eslint (лінтер)
- Prettier (форматувальник)
- Git

## Структура проєкту

```
qa-automation/
├── src/
│   └── temperature.ts          # модуль показового прикладу
├── tests/
│   └── temperature.test.ts     # тести модуля
├── .gitignore                  # файли, що не потрапляють до репозиторію
├── .prettierrc                 # правила форматування коду
├── eslint.config.mjs           # конфігурація лінтера
├── package.json                # залежності та скрипти запуску
├── tsconfig.json               # налаштування компілятора TypeScript
├── vitest.config.ts            # конфігурація раннера тестів і покриття
└── README.md                   # опис проєкту
```

Каталог `src/` містить код, що тестується, `tests/` містить тести. Індивідуальний модуль за варіантом також розміщується в `src/`, а його тести в `tests/`.

## Встановлення

Потрібні Node.js версії 20 або новішої та Git.

```bash
git clone <адреса репозиторію>
cd qa-automation
npm install
```

## Запуск

| Команда | Призначення |
| --- | --- |
| `npm test` | Одноразовий прогін усіх тестів |
| `npm run test:watch` | Режим спостереження: перезапуск при зміні файлів |
| `npm run coverage` | Прогін тестів із вимірюванням покриття |
| `npm run lint` | Статичний аналіз коду (ESLint) |
| `npm run format` | Автоформатування коду (Prettier) |

Після `npm run coverage` HTML-звіт доступний у файлі `coverage/index.html`.

Пороги покриття (задані у `vitest.config.ts`): рядки 80 %, гілки 80 %, функції 100 %.
